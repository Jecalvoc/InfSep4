🔢 Bits y Bytes: Los Ladrillos Digitales

Imagina que los bits son como pequeños interruptores que solo pueden estar en dos posiciones: 0 (apagado) o 1 (encendido).

Cuando juntamos 8 bits, formamos algo más grande llamado byte. ¡Es como tener 8 ladrillos para construir algo más grande!

Un byte puede representar una letra, un número o un símbolo. Por ejemplo, la letra "A" se guarda como un byte especial.

💾 Gigas y Megas: ¿Cuánto Cabe?

Así como medimos el peso en gramos y kilogramos, las computadoras miden el espacio en unidades diferentes:

Kilobyte (KB) = 1024 bytes

Megabyte (MB) = 1024 KB

Gigabyte (GB) = 1024 MB

¡Cada vez que subimos una unidad, multiplicamos por 1024! Por eso 1 GB = 1024 MB.

🏠 IPv4: La Dirección de tu Computadora

Cada computadora en una red necesita una dirección única, como tu dirección de casa. Esta dirección se llama IPv4.

Una dirección IPv4 tiene 4 números separados por puntos, como: 192.168.1.100

Cada número puede estar entre 0 y 255. ¡No puede ser 256 o más!

Por ejemplo, 192.168.1.300 NO es válida porque 300 es mayor que 255.

🌐 DNS: El Traductor de Internet

Cuando escribes www.google.com, tu computadora no entiende ese nombre. Necesita una dirección numérica.

El DNS (Sistema de Nombres de Dominio) es como un traductor: convierte nombres fáciles de recordar en direcciones IP numéricas.

Es como la agenda de tu teléfono: tú guardas "Mamá" pero el teléfono usa el número real para llamar.

El DNS NO cambia el contenido de las páginas, solo traduce nombres a números.

🎭 Máscara de Subred: Dividiendo la Red

La máscara de subred es como una regla que divide la dirección IP en dos partes:

Parte de red: Identifica a qué red pertenece (como el nombre de tu calle).

Parte de host: Identifica al dispositivo específico (como el número de tu casa).

Por ejemplo, con la máscara 255.255.255.0, en la IP 192.168.1.100:

• Los primeros 3 números (192.168.1) son la red

• El último número (100) es el host

🤖 DHCP: El Repartidor de IPs

DHCP es como un repartidor automático que da direcciones IP a todos los dispositivos que se conectan a la red.

Cuando conectas tu tablet o celular al Wi-Fi, el servidor DHCP le asigna automáticamente una IP disponible.

Funciona con cualquier dispositivo: con cable, Wi-Fi, celulares, tablets, impresoras, ¡todos!

Cada dispositivo recibe una IP diferente. No da la misma IP a todos.

🔒 Rangos Privados y NAT: Seguridad en la Red

Las IPs privadas (como 192.168.x.x) solo funcionan dentro de tu casa u oficina. No pueden salir a Internet directamente.

El NAT (Traducción de Direcciones de Red) es como un traductor en la puerta: toma las IPs privadas y las convierte en una IP pública para salir a Internet.

Así, todos los dispositivos de tu casa comparten una sola IP pública para navegar, pero cada uno tiene su IP privada interna.

¡Esto es más seguro porque oculta tus dispositivos del mundo exterior!

⚠️ Conflicto de IP: ¡Dos con la Misma Dirección!

Si dos dispositivos tienen la misma dirección IP en la misma red, ocurre un conflicto.

Es como si dos casas tuvieran la misma dirección: el cartero no sabría a cuál entregar el paquete.

Cuando hay conflicto, uno o ambos dispositivos pierden conexión. No pueden comunicarse correctamente.

Para solucionarlo, hay que cambiar la IP de uno de los dispositivos para que cada uno tenga una dirección única.

🔄 127.0.0.1: Hablando Contigo Mismo

La dirección 127.0.0.1 es especial. Se llama localhost y significa "esta misma computadora".

Es como hablarte a ti mismo en el espejo. Una computadora puede usar esta dirección para hacer pruebas y comunicarse consigo misma.

Se usa para pruebas locales, no para salir a Internet ni para comunicarse con otras computadoras.

Los programadores la usan mucho para probar programas antes de conectarlos a redes reales.

🛡️ Buenas Prácticas: Redes Seguras

Para tener una red segura y bien organizada, debemos seguir estas buenas prácticas:

✅ Usar rangos privados para dispositivos internos (192.168.x.x)

✅ Segmentar la red: separar dispositivos en diferentes redes según su función

✅ No exponer servidores internos directamente a Internet

✅ Proteger información sensible: servidores importantes como nómina deben estar en redes separadas y seguras

❌ NO poner todo en la misma red con IPs públicas

❌ NO dejar servidores importantes accesibles desde redes de invitados
